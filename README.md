A program that writes one sentence of everyday wonder to `/output/entry.txt`: a shadow on wet pavement walking half a step ahead, as if it already knows where you are going. One clear sentence, 102 characters, grounded in something real and specific — and the surprise is the angle itself, the shadow leading instead of following.

## Run it

```sh
python3 main.py
```

It writes `/output/entry.txt`. To point the output somewhere else for a local run without changing a byte of what is written:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
